## 1. وصف فكرة المشروع وهندسته المعمارية

### 🎯 فكرة المشروع وأهدافه:
يهدف المشروع إلى تصميم وتطوير نظام برمجي هندسي متكامل لبناء وتطبيق **مترجم حقيقي للغة برمجة عربية عالية المستوى**، مدعوماً بـ **بيئة تطوير ومحرر أكواد رسومي مستقل (Standalone IDE)**، وفق المعايير الأكاديمية الصارمة لمقرر بناء المترجمات (CS 351).

ينقسم النظام برمجياً ومعمارياً إلى **برنامجين تنفيذيين مستقلين تماماً (Two Independent Executables)**:
1. **المترجم المستقل (`CompilerProject_CPP.exe`):**
   - مطور كلياً بلغة **Modern C++20** النقية وبدون أي مكتبات خارجية لتوليد المترجمات (Handwritten Multi-Phase Compiler).
   - يطبق مراحل الترجمة الست الكلاسيكية كاملة: التحليل المعجمي، التحليل النحوي، بناء شجرة الإعراب المجردة (AST)، بناء جدول الرموز، التحليل الدلالي، توليد الكود الوسيط ثلاثي العناوين (TAC)، توليد كود لغة التجميع x86 Assembly، بالإضافة إلى مفسر كود وسيط مدمج فائق السرعة لتنفيذ البرامج في الذاكرة الحية ومعالجة مدخلات المستخدم لتعليمة `اقرا`.
   - يعمل كأداة سطر أوامر مستقلة (CLI) تقبل مسار الملف وخيار `--json` لتبادل البيانات البرمجية.
2. **محرر لغة البرمجة العربية (`LanguageEditor.exe`):**
   - بيئة تطوير متكاملة ذات واجهة رسومية عربية أصيلة تدعم اتجاه الكتابة من اليمين إلى اليسار (RTL).
   - توفر وظائف إدارة الملفات المتقدمة (جديد، فتح، حفظ، حفظ باسم)، شريط أرقام الأسطر المتزامن رأسياً، محرك التحليل اللحظي المباشر أثناء الكتابة، حقل إدخال مخصص لمدخلات المستخدم، زر تحديث الواجهة السريع، وثمانية تبويبات منظمة تعرض مخرجات مراحل المترجم الحقيقية في زمن حقيقي.

## 4. الشرح التفصيلي البرمجي لأكواد مترجم C++ وفق العناصر التحليلية التسعة

### 4.1 نماذج البيانات والرموز الأساسية (`Token.h`, `TokenType.h`, `Node.h`, `CompilationResult.h`)
- **1. وظيفة الجزء:** تعريف الكائنات الأساسية الحاملة لبيانات الرموز المعجمية، عقد شجرة الإعراب، وكائن نتيجة الترجمة الشامل المتبادل مع المحرر.
- **2. المدخلات:** قيم الرموز المعجمية، أنواعها، أرقام أسطرها، وأسماء عقد الشجرة.
- **3. المخرجات:** كائنات `Token` و `Node` مهيكلة وكائن `CompilationResult` القابل للتحويل إلى JSON.
- **4. المتغيرات المستخدمة:** `Value` (قيمة الرمز/العقدة)، `Type` (نوع الرمز)، `Line` (رقم السطر)، `Children` (قائمة الأبناء).
- **5. هياكل البيانات المستخدمة:** `std::vector<std::shared_ptr<Node>>` لإدارة أبناء شجرة الإعراب، `std::string` للنصوص.
- **6. الدوال والإجراءات المستخدمة:** `Node::Print()` لطباعة الشجرة بصرياً، `CompilationResult::ToJson()` لتحويل مخرجات الترجمة لصيغة JSON.
- **7. المكتبات المستخدمة:** `<string>`, `<vector>`, `<memory>`, `<sstream>`.
- **8. الملفات المرتبطة:** ترتبط به كافة ملفات المراحل التحليلية اللاحقة.
- **9. كيفية الارتباط بباقي أجزاء المشروع:** يمثل العقد البياني (Data Contract) الموحد في النظام.

```cpp
// مقطع من ملف Node.h - تمثيل عقد شجرة الإعراب المجردة
struct Node {
    std::string Value;     // نوع العقدة (مثل IfStatement, ReadStatement)
    std::string Name;      // اسم المعرف المرتبط بالعقدة
    std::string DataType;  // نوع البيانات
    std::string Val;       // القيمة الثابتة إن وجدت
    int Line = 0;          // رقم السطر المصدري
    std::vector<std::shared_ptr<Node>> Children; // العقد الفرعية
};
```

### 4.2 المحلل المعجمي واللغوي (`Lexer.h` & `Lexer.cpp`)
- **1. وظيفة الجزء:** قراءة النص المصدري العربي بترميز UTF-8 وتقسيمه إلى وحدات لغوية معجمية (`Tokens`)، والتعرف على الكلمات المفتاحية بكافة أشكال الهمزات (`اقرا`, `اقرأ`, `اقرء`)، وتطبيع الأرقام المشرقية (`٠-٩`) وتجاهل التعليقات.
- **2. المدخلات:** سلسلة نصية كاملة تحتوي على الكود المصدري العربي `sourceCode`.
- **3. المخرجات:** قائمة متتابعة من كائنات `std::vector<Token>`.
- **4. المتغيرات المستخدمة:** `_src` (النص المصدري)، `_pos` (المؤشر الحالي)، `_line` (عداد الأسطر).
- **5. هياكل البيانات المستخدمة:** `std::unordered_set<std::string>` لتخزين الكلمات المفتاحية بزمن بحث $O(1)$.
- **6. الدوال والإجراءات المستخدمة:** `Tokenize()`, `ReadIdentifierOrKeyword()`, `ReadNumber()`, `ReadString()`, `SkipWhitespaceAndComments()`, `IsEasternArabicDigit()`.
- **7. المكتبات المستخدمة:** `<cctype>`, `<sstream>`, `<unordered_set>`, `<string>`.
- **8. الملفات المرتبطة:** `Token.h`, `TokenType.h`, وموجه مباشرة للمحلل النحوي `Parser.cpp`.
- **9. كيفية الارتباط بباقي أجزاء المشروع:** يزود المحلل النحوي بالرموز المعجمية النظيفة والمرتبة.

```cpp
// مقطع من ملف Lexer.cpp - دعم الكلمات المفتاحية بالهمزات المختلفة وتطبيع الأرقام
const std::unordered_set<std::string> Lexer::Keywords = {
    "برنامج", "ثابت", "نوع", "متغير", "صحيح", "حقيقي", "منطقي", "حرفي", "خيط_رمزي",
    "اذا", "فان", "والا", "طالما", "استمر", "اعد", "حتى", "كرر", "الى", "اضف",
    "اقرا", "اقرأ", "اقرء", "اطبع", "صواب", "خطأ", "صح", "خطا"
};

Token Lexer::ReadNumber() {
    int startLine = _line;
    std::string numStr;
    while (_pos < _src.size() && (isdigit(_src[_pos]) || IsEasternArabicDigit(PeekUtf8(2)))) {
        // تحويل الأرقام المشرقية ٠-٩ إلى أرقام نظامية 0-9
        if (IsEasternArabicDigit(PeekUtf8(2))) {
            numStr += ConvertEasternDigit(ConsumeUtf8(2));
        } else {
            numStr += _src[_pos++];
        }
    }
    return Token(TokenType::Number, numStr, startLine);
}
```

### 4.3 المحلل النحوي وبناء شجرة الإعراب المجردة (`Parser.h` & `Parser.cpp`)
- **1. وظيفة الجزء:** فحص التراكيب النحوية وفق قواعد EBNF للغة العربية باستخدام خوارزمية الانحدار العودي التنازلي التنبؤي `LL(1)`، وبناء شجرة الإعراب المجردة (AST)، واسترجاع الأخطاء بنمط الهلع التوافقي (Panic Mode).
- **2. المدخلات:** مصفوفة الرموز المعجمية `std::vector<Token>`.
- **3. المخرجات:** العقدة الجذرية لشجرة الإعراب `std::shared_ptr<Node>` وقائمة الأخطاء النحوية `Errors`.
- **4. المتغيرات المستخدمة:** `_tokens`, `_pos` (فهرس الرمز الحالي).
- **5. هياكل البيانات المستخدمة:** شجرة ديناميكية من عقد `Node`، ومصفوفة سلاسل نصية للأخطاء.
- **6. الدوال والإجراءات المستخدمة:** `ParseProgram()`, `ParseBlock()`, `ParseStatement()`, `ParseReadStatement()`, `ParseIfStatement()`, `ParseLogicalOr()`, `ParseAdditive()`, `Synchronize()`.
- **7. المكتبات المستخدمة:** `<memory>`, `<vector>`, `<string>`, `<iostream>`.
- **8. الملفات المرتبطة:** `Lexer.h`, `Node.h`, وتمرر الشجرة للمحلل الدلالي ومولد الكود.
- **9. كيفية الارتباط بباقي أجزاء المشروع:** ينشئ الهيكل الشجري الذي تعتمد عليه كافة المراحل اللاحقة.

```cpp
// مقطع من ملف Parser.cpp - إعراب تعليمة اقرا بمرونة كاملة بالأقواس وبدونها
std::shared_ptr<Node> Parser::ParseReadStatement() {
    int line = Current().Line;
    Advance(); // تجاوز كلمة اقرا / اقرأ / اقرء
    bool hasParen = Match("("); // فحص القوس الاختياري
    auto varToken = ExpectType(TokenType::Identifier, "يجب كتابة اسم المتغير المراد القراءة إليه");
    if (hasParen) {
        Expect(")", "يجب إغلاق القوس ')' لتعليمة 'اقرا'");
    }
    Expect("؛", "يجب إنهاء تعليمة 'اقرا' بفاصلة منقوطة '؛'");
    auto readNode = std::make_shared<Node>("ReadStatement", varToken.Value, line);
    return readNode;
}
```

### 4.4 جدول الرموز وإدارة النطاقات (`SymbolTable.h` & `SymbolTable.cpp`)
- **1. وظيفة الجزء:** تخزين بيانات المعرفات (اسم، نوع البيانات، التصنيف، سطر التعريف، أسطر الاستخدام) والبحث عنها بزمن ثابت.
- **2. المدخلات:** أسماء وخصائص الرموز المعرفة من شجرة الإعراب.
- **3. المخرجات:** سجلات الرموز `SymbolInfo` ومعلومات التتبع الدلالي.
- **4. المتغيرات المستخدمة:** `_table` (جدول التجزئة الرئيسي).
- **5. هياكل البيانات المستخدمة:** `std::unordered_map<std::string, SymbolInfo>`.
- **6. الدوال والإجراءات المستخدمة:** `AddSymbol()`, `Lookup()`, `Contains()`, `AddReference()`, `Print()`.
